Currency Converter - Projeto A3

Sistema de conversão de moedas com foco em qualidade de software

🎯 Sobre o Projeto

O Currency Converter é um sistema de conversão de moedas desenvolvido em Java com interface gráfica Swing. O projeto permite aos usuários converter valores entre diferentes moedas utilizando taxas de câmbio em tempo real fornecidas pela ExchangeRate-API.

Objetivo

Demonstrar na prática técnicas de qualidade e teste de software, aplicando estratégias de teste, automação, métricas, estimativas e revisão de código em um sistema real.
